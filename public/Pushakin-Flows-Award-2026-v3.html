LIHUM — Lihat & Undah Mandiri (Khusus)

Portal Galeri Foto Publik — Embedded di Web UIN Antasari

URL
lihum.synclicen.workers.dev
📸 Apa itu LIHUM?
Galeri foto publik otomatis dari folder PUBLIC proyek. 1-klik publish.
🔧 Cara Kerja
Manager klik "Publish ke LIHUM" → auto-buat gallery dengan nama & deskripsi proyek.
🔒 Privasi Terjaga
Hanya folder PUBLIC di-share. Folder PRIVATE tidak pernah dipublikasikan.
📊 Statistik
54 galeri aktif, ribuan foto kegiatan, publik tanpa login.
🌐
Embedded di Web UIN Antasari — LIHUM di-embed via iframe di website resmi uin-antasari.ac.id sebagai portal kehumasan publik. Masyarakat dapat melihat & mengunduh foto kegiatan tanpa login.
📸 Bukti: LIHUM Gallery Publik — lihum.synclicen.workers.dev LIVE
